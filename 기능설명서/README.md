### 실사용 모드 데모 계정

세 계정이 **하나의 가구(household)** 를 공유합니다. 각자 다른 기기에서 로그인해도 같은 위임을 봅니다.

| 역할 | 아이디 | 비밀번호 | 이름 |
|---|---|---|---|
| 위임자 (어머니) | `mother` | `carepass1` | 이순자 |
| 대리인 (딸) | `daughter` | `carepass2` | 이지은 |
| 공동보호자 (아들) | `son` | `carepass3` | 이준호 |

> 비밀번호는 환경변수(`CP_PW_*`)로 덮어쓸 수 있습니다. 은행 인증을 대체하려는 것이 아니라
> **세션이 서버에서 검증된다는 구조**를 보이는 범위입니다.

## 한 문단 요약

계좌를 통째로 넘기는 위임이 아니라, **업무별·한도별 금융 대리권**을 만들고 그 행사 내역을
블록체인으로 증명하는 지갑입니다. 어머니(위임자)가 미리 **결제 가능 기관·건당/월 한도·기간**을
정해 위임장에 서명해 두면, 딸(대리인)은 어머니의 카드·비밀번호를 받지 않고 **자기 명의 인증수단**으로
그 범위 안의 의료비만 결제를 요청합니다. 범위를 벗어나거나 평소와 다른 결제는 **보류**되고,
아들(공동보호자)에게 **알림**이 갑니다. 모든 행위의 해시가 온체인에 남습니다.

## 5분 시연 루트 (처음 보는 사람에게)

심사용 데모(`/`)를 열고 아래 순서로 시나리오 버튼을 누릅니다.

| 순서 | 버튼 | 보여주는 것 |
|---|---|---|
| 1 | **iM뱅크 홈** | 별도 앱이 아니라 iM뱅크 앱의 한 기능이라는 것 |
| 2 | **위임장 직접 서명** | 건별 승인을 없애는 근거 — 설정 시점의 일회성 동의 |
| 3 | **정상 병원비 8만원** | **신뢰 기관이라 묻지 않고 즉시 승인** — 치매 위임자가 매번 승인할 수 없다는 전제의 답 |
| 4 | **미등록 결제처(사칭)** | 공공데이터로 가짜 병원 차단 |
| 5 | **청구서 QR · 사칭 검증** | 이름까지 베낀 사칭도 **전자서명**으로 구분 |
| 6 | **한도 아래로 쪼개기(구조화)** | **신뢰 기관인데도 잡힌다** — 면제한 것은 결제처 축 하나뿐 (**킬러 차별점**) |
| 7 | **보호자 알림·이의제기** | 결제 권한 없는 가족이 감시자로 작동. 집행된 건은 **장부 롤백**까지 |
| 8 | 인스펙터 **블록체인 원장** 탭 | 실제 Sepolia에서 조회해 해시 대조 |

3번과 6번을 **붙여서** 보여주는 것이 이 서비스의 핵심입니다. *"믿는 병원은 묻지 않는다"* 와
*"믿는 병원에서도 쪼개면 잡는다"* 가 같이 성립해야 설계가 설명됩니다.

## 구현 범위 (정직하게)

| 구분 | 내용 |
|---|---|
| **실제로 동작** | 위임 설정·위임장 서명, 결제요청→판정→알림→승인/거부 전 과정, 규칙+z+구조화 탐지, 신뢰 기관 자동승인·사후 되돌리기, 공공데이터 결제처 확인, **심평원 Open API 실시간 조회(기관 등록 시)**, ECDSA 청구서 서명 검증, Sepolia 온체인 기록·조회, 로그인/세션/역할 권한/감사 체인 |
| **화면 시뮬레이션** | 보안 센터(원격 VC 폐기·후견인 전환), 월간 리포트 |
| **설계 발표 범위** | 실제 은행 코어 API 연동, 생체인증, 다중서명, 신뢰 목록 주기 재점검 배치, 실제 환수(은행 분쟁처리) |
| **데모용 축약** | 냉각기간 24h → 60초, 결제 이력은 합성 데이터 |

**iM Zero AI 상담은 외부 LLM을 호출하지 않습니다.** 현재 위임 상태를 반영한 상태 기반 답변이고,
음성 인식·합성만 브라우저 Web Speech API를 씁니다. 실서비스는 iM뱅크 iM Zero와 연계를 전제로 합니다.
