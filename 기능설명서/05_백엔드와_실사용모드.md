# 05. 백엔드와 실사용 모드

멘토 지적 *"백엔드 + 로그인 + 배포 — 실제로 열어보게"* 에 대한 대응입니다.
Vercel 서버리스 함수 4개로 구성되어 있습니다 (`carepass-prototype/api/`).

## 1. 왜 서버가 필요한가

> **데모 계정 3개가 하나의 가구(household)를 공유합니다.**
> 어머니가 권한을 주고, 딸이 결제를 요청하고, 아들이 예외만 통지받습니다.
> **세 사람이 각자 기기에서 로그인해도 같은 데이터를 봅니다** — 그것이 이 서버의 존재 이유입니다.

## 2. 엔드포인트

| 경로 | 역할 |
|---|---|
| `GET /api/health` | 배포 확인 · 저장소 모드 보고 → `{"ok":true,"storage":"kv"}` |
| `/api/session` | 로그인 · 세션 조회 · 로그아웃 |
| `/api/state` | 가구 공유 상태 (위임 하나를 세 계정이 같이 본다). rev 기반 폴링 |
| `GET /api/audit` | 가구 공유 감사 로그 조회 (최근 100건) |

## 3. 인증 — 서버가 검증한다

- 아이디+비밀번호를 **서버가** 확인합니다.
- 비밀번호는 길이가 달라도 타이밍이 새지 않도록 **SHA-256 해시를 떠서 상수시간 비교**합니다
  (`crypto.timingSafeEqual`).
- 존재하지 않는 아이디도 더미 값과 비교해 **아이디/비밀번호를 구분해 거부하지 않습니다.**
- 세션은 **HMAC-SHA256 서명된 HttpOnly 쿠키**입니다. 만료 7일.
  서명 비교도 상수시간이고, 길이가 다르면 즉시 거부합니다.

```
토큰 = base64url({a: 계정, iat, exp}) + "." + HMAC-SHA256(본문, SESSION_SECRET)
```

환경변수: `SESSION_SECRET`, `CP_PW_DELEGATOR` / `CP_PW_DELEGATE` / `CP_PW_GUARDIAN`

## 4. 역할 권한 — 클라이언트를 고쳐도 서버가 막는다

`api/state.js`의 `ALLOW` 표가 action별 허용 역할을 고정합니다.

| action | 허용 역할 |
|---|---|
| `setup` · `consent` · `consentRevoke` | **위임자만** |
| `request` | **대리인만** |
| `decide` (승인/거부) · `revoke` · `restore` · `sos` | **위임자만** |
| `objection` · `ack` | **공동보호자만** |
| `raise` (한도 상향 요청) | **대리인만** |
| `raiseCancel` | 위임자 또는 대리인 |

위반하면 `403` + `"공동보호자은(는) 'decide' 권한이 없습니다"` 식의 메시지가 돌아옵니다.

> **대리인은 '요청'만 하고 승인할 수 없습니다. 보호자는 결제 권한이 아예 없습니다.**
> 이것이 화면 제어가 아니라 서버 규칙이라는 점이 중요합니다.

## 5. 감사 로그 — 해시 체인으로 묶는다

서버가 수신 시각과 **직전 항목의 해시**를 엮어 체인을 만듭니다.

```js
entry.chain = sha256( (직전 항목의 chain 또는 "000…0") + JSON.stringify(entry) )
```

중간 한 건을 지우거나 바꾸면 **뒤가 전부 어긋납니다.** 세 계정이 같은 로그를 보므로
"누가 무엇을 했는지"를 함께 확인합니다.

## 6. 냉각기간 — 서버가 판정한다

한도 상향은 즉시 반영되지 않고 **냉각기간**을 거칩니다.

| 항목 | 값 |
|---|---|
| 기본 길이 | **60초** (실서비스 24h의 데모 축약) |
| 환경변수 | `CP_RAISE_MS` 로 조정 (테스트에서 기다리지 않아도 됨) |
| 상향 요청 | 대리인이 요청 → 위임자·대리인 모두 취소 가능 |
| 알림 | 신뢰인(사회복지사 김민서)과 공동보호자에게 통지 |
| 온체인 | `limitRaiseRequested` 기록 |

**서버리스라 타이머를 둘 수 없으므로**, 냉각기간이 끝난 상향은 **읽는 시점에** 반영합니다
(`settleRaise()`). 로컬 타이머로 한도를 바꾸면 다음 폴링에 서버 값으로 되돌아가기 때문에,
앱 모드에서는 상향도 종료 판정도 모두 서버가 담당합니다.

## 7. 저장소

| 조건 | 동작 |
|---|---|
| `KV_REST_API_URL` · `KV_REST_API_TOKEN` 있음 | **Vercel KV에 영구 저장** (현재 배포본) |
| 없음 | 인스턴스 메모리 사용 + 화면에 *"서버 재시작 시 비워진다"* 고 그대로 표시 |

현재 배포본은 KV가 연결돼 있어(`storage:"kv"`) 서버 기록이 재배포·재시작 후에도 남습니다.

## 8. 실사용 모드 `/app`

데모 장치(인스펙터·시나리오 버튼·계정 토글)를 전부 걷어내고 폰 화면만 전체로 띄웁니다.

- **로그인 전에는 아무것도 보이지 않습니다.**
- 로그인한 사람의 **역할 화면만** 보입니다.
- 심사용 데모(`/`)는 그대로 유지됩니다.

## 9. 배포 설정 (`vercel.json`)

| 항목 | 값 |
|---|---|
| `cleanUrls` | 활성 |
| 보안 헤더 | `X-Content-Type-Options`, `Referrer-Policy`, `Permissions-Policy` |
| Permissions-Policy | **마이크만 self 허용** (음성 인식용) |
| 캐시 | `/data` 1시간 · `index.html` no-cache |
| 리라이트 | `/app` |

## 10. 서버가 없어도 동작한다

ZIP으로 받아 `index.html`을 파일로 열면 **백엔드 관련 UI가 아예 나타나지 않고**,
앱은 로컬 상태로 그대로 동작합니다. 백엔드는 "있으면 쓰고, 없으면 그대로 동작"하는 구조입니다.
